# ルール・計算仕様

本アプリのルールエンジンの仕様と、採用した初期値・判断の記録です。
ルールプロファイル ID: `jp-riichi-standard-v1`（バージョン 1.0.0）。設定画面で変更したルールは `custom` として保存され、各対局は開始時点のルールを保持します。

### 実装時に採用した細則（設定で変更可能なものを含む）

仕様書・ユーザー回答で決まっていなかった細則は、以下の一般的な扱いとしました。異なる扱いが必要な場合は指示してください。

- **包の支払い**: ツモは責任者がロン相当額を全額負担、ロンは放銃者と責任者で折半。複合役満では包の対象役満の分だけに適用。本場はツモなら責任者、ロンなら放銃者が支払う。
- **ダブロンの本場・供託**: 放銃者の下家側に近いアガリ者が受け取る（上家取り。設定で「本場は両者に付く」に変更可）。
- **流し満貫**: 満貫ツモ相当の支払い。本場は付けず、ノーテン罰符は発生しない。供託は残る。親の連荘は親のテンパイで判定。
- **途中流局**: 親の連荘・本場+1、リーチ棒は供託に残る。
- **緑一色**: 發が無くても成立（設定で「發が必須」に変更可）。
- **リーチ**: 持ち点がリーチ棒（1000点）未満の人はリーチできない。

## 2. 計算エンジン（`src/domain`）

処理順（仕様書 1.1）: 入力検証 → 牌の物理枚数検証 → 局・場況の検証 → 全分解候補の生成 → 候補ごとに役満判定／通常役判定・排他処理 → ドラ → 翻 → 符 → 基本点 → 支払い（本場・供託・包を別明細） → 最高点の候補を採用 → 支払い合計の整合確認。

- **牌**: 34種×4枚。赤五は通常の五の内数。ドラは表示牌の次の牌（数牌 9→1、風 北→東、三元 中→白）。
- **アガリ形**: 4面子1雀頭（槓子は1面子）、七対子（同じ牌4枚を2対子とは数えない）、国士無双。アガリ牌が雀頭・刻子・順子のどれに入るかで待ち（両面・嵌張・辺張・双碰・単騎）を判定し、ロンで完成した刻子は明刻扱い。
- **役**: 立直・ダブル立直・一発・門前清自摸和・断么九・平和・一盃口・役牌（白・發・中・自風・場風）・嶺上開花・槍槓・海底摸月・河底撈魚・七対子・対々和・三色同順・一気通貫・混全帯么九・三色同刻・三暗刻・三槓子・小三元・混老頭・二盃口・純全帯么九・混一色・清一色。副露時の食い下がり、門前限定役、上位役による排他（二盃口⊃一盃口、純チャン⊃チャンタ、清一色⊃混一色、ダブル立直⊃立直）をデータで管理。
- **役満**: 国士無双・四暗刻・大三元・小四喜・大四喜・字一色・緑一色・清老頭・四槓子・九蓮宝燈・天和・地和（人和は設定で満貫／役満）。役満成立時は通常役・ドラを点数に加えない。
- **符**: 副底20、門前ロン10、ツモ2（平和ツモを除く）、刻子・槓子（中張/么九 × 明/暗 × 刻/槓）、役牌雀頭、嵌張・辺張・単騎2。平和ツモ20符・平和ロン30符・七対子25符・副露手の20符形は30符。10符単位に切り上げ。
- **点数**: 基本点＝符×2^(翻+2)。満貫2000・跳満3000・倍満4000・三倍満6000・役満8000（×役満数）。ロンは子×4・親×6、ツモは子が親×2・子×1、親は×2オール。各支払いを100点単位に切り上げ。本場はロン300点・ツモ各100点。供託は1本1000点。
- **ドラだけのアガリは不成立**（エラー `NO_YAKU`）。無効な入力に対して仮の点数は返さず、エラーコード（仕様書 第19章）とユーザー向けの修正方法を返す。

## 3. 局進行・精算（`src/domain/round`, `src/domain/settlement`）

- 対局はイベント列（アガリ・流局・途中流局・チョンボ・終了・状態修正）として保存し、状態は常に再生で求める。不正なイベントは状態を変えずに拒否する。
- 局ごとに「持ち点合計＋供託」が変わらないこと（ゼロサム）を検証し、崩れた場合は `POINT_CONSERVATION_FAILED` で拒否する。
- 連荘: 親のアガリ、流局時の親のテンパイ、途中流局。親流れ時はアガリなら本場0、流局なら本場+1。
- 終了: 南4局の終了（親流れ）、オーラスのアガリやめ・テンパイやめ（親がトップの場合に選択）、トビ（0点未満）、手動終了。
- 精算: 収支＝(持ち点−返し点)/1000＋ウマ＋オカ（トップ）。同点は起家に近い方が上位（設定で等分も可）。合計がゼロになることを表示で確認。

## 4. 対応範囲と未対応

**未対応**（該当する状況はアプリで計算できません。推測で点数を出さないようにしています）

- 西入（延長戦）、アガリ放棄、誤ロン・誤ツモ・多牌・少牌の個別処理（チョンボとして記録は可能）
- 大車輪・十三不塔などのローカル役、流し満貫以外の特殊な流局精算
- 牌の画像認識、オンライン対局、AIアドバイス（設計書で対象外）

**入力に頼る項目（既知の制約）**

- 捨て牌・ツモ順を記録しないため、**フリテン・一発・海底・河底・嶺上・槍槓・天和・地和はユーザーの入力どおりに扱います**。ロン時のフリテンは「フリテンではない／未確認／フリテン」を選び、未確認なら警告を表示します（仕様書 10.6）。
- 他家の槓は入力されないことがあるため、槓ドラ表示牌の枚数は「アガった人自身の槓の数以上」だけを確認します。
- 包の責任者は、アガった人に該当する牌（三元牌・風牌など）を鳴かせた人の中から選ぶ方式です（最後の牌を鳴かせたかどうかの順序までは検証しません）。
- 九種九牌・四風子連打・四槓散了の成立条件は、入力された手牌がある場合のみ参考表示し、宣言内容を信じて記録します。
