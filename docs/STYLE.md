# 画面表記のルール

アプリ内の文言・数値の書き方をそろえるためのルールです。数値やルールの表示は `src/ui/format.ts` の関数を使います。

| 項目 | ルール | 例 |
| --- | --- | --- |
| 点数 | 3桁区切り＋「点」（`fmtPoints`） | 30,000点 |
| 持ち点（表の中など単位が明らかな所） | 3桁区切りのみ（`fmtNumber`） | 32,000 |
| 収支・ウマなどの符号付き数値 | プラスは「+」、マイナスは「−」（`fmtSigned`） | +32.0／−15.0 |
| ウマ | 1位から順に「／」で区切る（`fmtUma`） | +30／+10／−10／−30 |
| 人数 | 「4人打ち」「3人打ち」（`playerCountLabel`） | 3人打ち |
| ルールの概要 | 新規対局・設定・精算で同じ文面（`ruleSummary`） | 3人打ち・東南戦・35,000点持ち 40,000点返し・… |
| 局 | 場風＋局数＋半角スペース＋本場 | 東1局 0本場 |
| ラベルと値 | 全角コロン「：」で区切る | 入力先：手牌／リーチ棒：A・B |
| 括弧 | 日本語の文中は全角括弧 | 満貫（4翻30符） |
| 翻・符 | 数字と単位の間に空白を入れない | 2翻30符 |
| 文章 | 説明・注意・エラーの文は「。」で終える。箇条書きの短い項目や見出しには付けない | 役がありません。 |
| リーチの呼び方 | 操作は「リーチ」「ダブルリーチ」、役の一覧では役名「立直」「ダブル立直」 | — |
| 座席 | 固定の座席は「東席・南席・西席・北席」、局ごとの風は「自風」。北家は3人打ちのツモ支払いの説明（「北家分を折半」）でのみ使う | 東席（起家）／自風 東 |
| 敬称 | 文中の名前には「さん」を付ける。表・ボタン・チップなど名前だけの所には付けない | Aさんのアガリ条件／ボタン「A」 |
| ボタン | 操作は動詞の終止形でそろえる（例外: 理牌・削除・クリア などの短い道具ボタン） | 記録する／保存する／対局を始める |
