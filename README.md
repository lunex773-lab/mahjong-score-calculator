# 麻雀点数計算 🀄

牌を並べるだけで、役・翻・符・点数・支払い、そして半荘終了時の順位・ウマ・オカまで計算できる、スマートフォン向けの日本式リーチ麻雀アプリです。

**▶ アプリを使う: https://lunex773-lab.github.io/mahjong-score-calculator/**
（`main` に取り込まれると GitHub Actions でビルド・公開されます。初回のみ下記「公開設定」が必要です）

## 主な機能

- **3D の回転する麻雀卓**: 自分の席から斜めに見下ろす立体の卓。指で横にスライドすると卓がターンテーブルのように回り、離すと最寄りの席で止まります（下のタブでも切替可）。席の札と局情報は常に正面を向きます。
- **俯瞰ボタン**: 4人分の手牌・副露・アガリ牌とドラ表示牌を、卓を真上から見た配置でまとめて表示。
- **牌の入力**: 画面下の牌一覧から **タップで追加**、**ドラッグで好きな位置に挿入**。手牌の牌はドラッグで並べ替え、卓の外へドラッグで削除。元に戻す／やり直し対応。卓全体で同じ牌は4枚まで（赤牌はルールの枚数まで）。
- **副露**: チー・ポン・大明槓・加槓・暗槓と鳴き元を記録。
- **自動採点**: 全分解候補とアガリ牌の割当てを列挙し、最も高い候補を採用（高点法）。役・翻・符の内訳、基本点、支払い（本場・供託・包を区別）を表示。
- **対局管理**: 連荘・親流れ・本場・供託、荒牌流局（ノーテン罰符）、流し満貫、途中流局（九種九牌・四風子連打・四家立直・四槓散了・三家和）、チョンボ、ダブロン、オーラスのアガリやめ・テンパイやめ、トビ終了。
- **精算**: 順位・ウマ・オカ・同点処理。対局の記録から算出するモードと、最終持ち点を直接入力するモード。合計がゼロになることを検証。
- **履歴**: 局ごとの点棒移動、最後の局の取り消し、局の状態の手動修正。
- **ルール設定**: 赤ドラ枚数、喰いタン、切り上げ満貫、数え役満、ダブル役満、複数ロン、途中流局、包、ウマ・オカなど。設定の矛盾は保存前に検出。対局は開始時点のルールで固定されます。
- **オフライン対応・端末内保存**（PWA。ホーム画面に追加して使えます）。
- **iPhone 向けの調整**: iPhone 14（390×844）・iPhone 17（402×874）を想定。ノッチ／Dynamic Island・ホームバーの余白、入力時の自動拡大の防止（入力欄16px）、長押しメニューの抑止、マイナス値の入力用 ± ボタン、動的ビューポート（dvh）に対応。

## 起動・ビルド

Node.js 22 以上が必要です。

```bash
npm install
npm run dev        # 開発サーバー http://localhost:5173
npm run build      # 本番ビルド（dist/）
npm run preview    # ビルド結果の確認
```

## テスト

```bash
npm run typecheck  # TypeScript（strict）の型チェック
npm test           # 単体テスト（Vitest）
npm run e2e        # E2Eテスト（Playwright・スマホ画面サイズ）
npm run test:diff  # 独立実装との差分テスト（要: pip install mahjong==1.2.1）
```

| 単体テスト `tests/unit/game.test.ts` | 局進行（連荘・親流れ・本場）、ダブロン、頭ハネ、流局（罰符 1〜3人テンパイ）、流し満貫、途中流局、四家立直、チョンボ、オーラスのアガリやめ、トビ、残供託、ウマ・オカ・同点 | 合格 |

| 差分テスト `tests/differential/` | ランダムに生成した計40,000手を独立実装と照合（七対子・国士・三色・一通・大三元・大四喜等を含む） | 不一致 0 件 |

## 技術構成

- Vite + React 19 + TypeScript（strict）、Zod（保存データ・ルール設定の検証）、Vitest、Playwright
- 設計書は React Native / Expo を指定していましたが、既存アプリが GitHub Pages 公開の Web アプリだったため、ユーザー確認のうえ **Web（PWA）** で実装しました。計算エンジンは UI から独立しているため、将来ネイティブ版に移植できます。
- 状態管理は追加ライブラリを使わず React の `useReducer` で実装（設計書の Zustand は不採用）。保存は SQLite ではなく端末の `localStorage`（読み込み時にスキーマ検証）。

```
src/
  domain/                 UI に依存しない計算エンジン（純粋関数）
    rules.ts              ルールプロファイルと設定矛盾の検証
    errors.ts             エラーコード（仕様書 第19章）
    mahjong/              牌・手牌検証・分解・役・符・ドラ・点数・支払い・採点パイプライン
    round/game.ts         局進行（イベント列の再生、点棒移動、ゼロサム検証）
    settlement/           順位・ウマ・オカ
  components/             牌（SVG描画）・牌一覧・手牌列・ドラッグ・回転する卓・ダイアログ
  features/               手牌編集・アガリ/流局入力・計算内訳・精算・履歴・設定・ガイド
  store/                  画面横断の状態（Undo/Redo、保存）
  infrastructure/         端末内保存
tests/                    単体・固定照合・差分・E2E
```

牌は画像やフォント素材を使わず SVG で描画しているため、ライセンス上の制約はありません。

## 公開設定（初回のみ・重要）

**公開サイトが真っ白で起動しない場合は、ほぼこの設定が原因です。**「Deploy from a branch」のままだと、ビルド前のソースがそのまま公開され、ブラウザがプログラムを読み込めません（アプリ側で「起動できませんでした」と案内を表示します）。

GitHub のリポジトリ設定 **Settings → Pages → Build and deployment → Source** を **「GitHub Actions」** に変更してください。以降は `main` への push ごとに、型チェック・単体テスト・E2E が通った場合のみ自動で公開されます。
