# 麻雀点数計算機 🀄

スマホ向けの麻雀（リーチ麻雀）点数計算アプリです。ビルド不要の静的Webアプリなので、`index.html` をブラウザで開くだけで使えます。

**▶ アプリを使う: https://lunex773-lab.github.io/mahjong-score-calculator/**

## 使い方

スマホやPCのブラウザで `index.html` を開いてください。ローカルサーバーを立てる場合は:

```
python -m http.server 8000
```

を実行して `http://localhost:8000` にアクセスします。スマホではブラウザの「ホーム画面に追加」でアプリのように使えます。

## 機能

### 点数計算タブ
- 親／子、ロン／ツモ、翻（1〜13+）、符（20〜110）を選んで即座に点数を表示
- 支払いの内訳を表示（ツモ時の子・親の支払い、親のオール払い）
- 本場・供託（リーチ棒）の加算に対応
- 切り上げ満貫（30符4翻・60符3翻を満貫扱い）のオプション
- ありえない組み合わせ（20符ロンなど）には注意書きを表示

### 符の計算タブ
- あがり方・待ちの形・雀頭・面子を選ぶだけで符を自動計算
- 七対子（25符固定）・平和ツモ（20符固定）・食い平和形（30符扱い）に対応
- 計算した符をワンタップで点数計算タブに反映

### 早見表タブ
- 子・親それぞれの点数早見表（1〜4翻 × 20〜110符、ロン／ツモ）
- 満貫〜役満の点数一覧

### 使い方タブ
- 麻雀初心者向けの解説（翻と符のしくみ、アプリの使い方の流れ）
- 用語ミニ辞典（親・子・ロン・ツモ・本場・供託・満貫）とよくある質問

## 点数計算のルール

- 基本点 = 符 × 2^(2+翻)（2000点で満貫に切り上げ）
- ロン: 子は基本点×4、親は基本点×6（100点単位に切り上げ）
- ツモ: 子は「親が基本点×2・子が基本点×1」、親は「基本点×2オール」（各100点単位に切り上げ)
- 本場: ロン+300点／本場、ツモ+100点／人／本場
- 満貫 8000/12000、跳満 12000/18000、倍満 16000/24000、三倍満 24000/36000、役満 32000/48000
